# SnapClass – AI Attendance System

SnapClass is an AI-powered classroom attendance system that automates attendance using **Face Recognition and Voice Recognition**, with QR-based course enrollment.

## 🚀 Features

- 👤 Face ID Attendance
- 🎙️ Voice ID Attendance
- 📱 QR-based Course Enrollment
- 👨‍🏫 Teacher Dashboard
- 👨‍🎓 Student Dashboard
- 📊 Attendance Records
- 🔐 Secure Authentication
- 📸 Photo-based Attendance
- 🎙️ Sequential Voice Attendance

## 🛠️ Technologies

## 🧠 AI Components

### Face Recognition
The system identifies students from classroom photographs using facial embeddings.

### Voice Recognition
Students can respond verbally, and their voice embeddings are compared against stored voice data.

### QR Enrollment
Teachers can share a course QR code/link, allowing students to quickly enroll in a subject.
